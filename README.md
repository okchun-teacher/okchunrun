# 젤리런 추첨기 (okchunrun)

젤리 캐릭터들이 장애물 코스를 달리고, 먼저 골인한 순서대로 당첨되는 3D 추첨기입니다.
움직임은 전부 랜덤이며, 캐릭터를 누르면 그 캐릭터 시점으로 볼 수 있습니다.

- 실행: `index.html` (GitHub Pages를 켜면 주소로 바로 접속)
- 맵: 빙글빙글 막대 · 문 뚫기 · 데굴데굴 공 언덕 · 조마조마 발판 · 쿵쾅 진자 다리 · 종합 코스
